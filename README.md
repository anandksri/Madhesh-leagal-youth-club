# Madhesh Legal Youth Club

> **Know Your Rights. Know Your Law.**

A modern, responsive website for Madhesh Legal Youth Club, a youth-led non-profit organization based in Birgunj, Nepal, focused on promoting legal awareness and helping people understand their rights, duties, and access to justice.

## About the Organization

Madhesh Legal Youth Club is a non-profit initiative working to promote practical legal awareness throughout Nepal.

The organization aims to:

- Raise awareness about legal rights and responsibilities
- Help people understand basic legal concepts
- Encourage people to ask questions about their legal rights
- Support communities with limited access to legal information
- Challenge outdated social concepts and mindsets through legal education
- Promote a society where people understand and exercise their rights responsibly

## Website Features

- Organization introduction and mission
- About and legal-awareness content
- Team and leadership information
- Initiatives and community activities
- Legal-awareness resources
- Responsive gallery with lightbox functionality
- Contact and organization information
- Responsive design for desktop and mobile devices

## Getting Started

Clone the repository:

```bash
git clone https://github.com/anandksri/Madhesh-leagal-youth-club.git
cd Madhesh-leagal-youth-club
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Development Notes

Generated directories such as `node_modules`, `.vite`, and `dist` should remain outside version control. Dependencies should be installed locally rather than committed to the repository.

Do not commit API keys, credentials, `.env` files, or other sensitive configuration.
